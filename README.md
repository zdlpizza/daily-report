# 📋 日报记录系统

基于 Gitee Pages + Gitee API 搭建的个人日报记录系统，无需服务器，完全免费。

## ✨ 功能特性

- 📝 Markdown 编辑器，支持实时预览
- 📅 按日期管理日报，支持任意日期查看/编辑
- 📚 左侧历史列表，快速切换历史日报
- 💾 一键保存到 Gitee 仓库（自动创建/更新文件）
- 🗑 支持删除日报
- ⌨️ `Ctrl+S` 快捷键保存
- 📄 内置日报模板，快捷插入常用章节
- ⚙️ 配置信息存储在本地浏览器，无需修改代码

---

## 🚀 部署步骤

### 第一步：在 Gitee 创建仓库

1. 登录 [Gitee](https://gitee.com)
2. 点击右上角 **+** → **新建仓库**
3. 仓库名建议填写 `daily-report`
4. 勾选 **使用 README 文件初始化仓库**
5. 点击创建

### 第二步：开启 Gitee Pages

1. 进入仓库 → 顶部菜单 **服务** → **Gitee Pages**
2. 分支选择 `master`，点击 **启动**
3. 记录生成的访问地址，格式为：`https://你的用户名.gitee.io/daily-report/`

### 第三步：上传本项目文件

将以下文件上传到仓库根目录：

```
index.html
style.css
config.js
gitee.js
app.js
README.md
```

上传方式任选：
- 直接在 Gitee 网页上传文件
- 使用 Git 命令推送
- 使用 Gitee 桌面客户端

### 第四步：生成私人令牌

1. 登录 Gitee → 右上角头像 → **设置**
2. 左侧菜单 → **私人令牌** → **生成新令牌**
3. 令牌描述填写：`daily-report`
4. 权限勾选：✅ **projects**（仓库读写）
5. 点击提交，**复制并保存 Token**（只显示一次！）

### 第五步：配置系统

1. 打开部署好的页面（Gitee Pages 地址）
2. 点击右上角 **⚙️ 配置** 按钮
3. 填写以下信息：
   - **Gitee 用户名**：你的 Gitee 账号用户名
   - **仓库名**：`daily-report`（或你自定义的仓库名）
   - **日报目录**：`reports`（推荐，或留空存根目录）
   - **私人令牌**：粘贴第四步生成的 Token
4. 点击 **保存配置**

配置完成后即可正常使用！

## 📖 使用说明

| 操作 | 方法 |
|------|------|
| 写今日日报 | 打开页面，默认加载今天日期 |
| 切换日期 | 点击顶部日期选择器，或点击左侧历史列表 |
| 快捷填充 | 点击「今日工作」「明日计划」等快捷按钮 |
| 保存日报 | 点击「💾 保存日报」或按 `Ctrl+S` |
| 预览效果 | 点击「👁 预览」切换 Markdown 渲染视图 |
| 查看历史 | 右侧历史列表点击对应日期 |
| 删除日报 | 鼠标悬停历史列表条目，点击 🗑 图标 |

## 📁 日报存储格式

日报以 Markdown 文件保存在仓库中，文件名为日期：

```
reports/
├── 2026-10-09.md
├── 2026-10-08.md
└── 2026-10-07.md
```

每份日报格式示例：

```markdown
# 日报 2026-10-09

## 今日工作
- 完成了 XX 功能开发

## 明日计划
- 继续 XX 模块联调

## 遇到的问题
- 无

## 其他备注
- 
```

## 🔒 安全说明

- Token 仅存储在本地浏览器的 `localStorage` 中，不会上传到任何第三方
- 建议将 Gitee 仓库设置为**私有**，防止日报内容被他人查看
- 如果 Token 泄露，及时在 Gitee 设置中删除并重新生成

## 🛠 本地调试

直接用浏览器打开 `index.html` 即可，但由于浏览器跨域限制，本地调用 Gitee API 可能失败。建议使用本地服务器：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node.js
npx serve .
```

然后访问 `http://localhost:8080`
